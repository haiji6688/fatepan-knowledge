# 流派与排盘口径（methodology）

> 本文档记录 fatepan.com 排盘引擎的实际口径。解读口径分歧是命理 AI 幻觉的主要来源之一，先声明口径，再做结论。

## 一、流派：传统三合派

- 十二宫安星以紫微星系（紫微 / 天机 / 太阳 / 武曲 / 天同 / 廉贞）与天府星系（天府 / 太阴 / 贪狼 / 巨门 / 天相 / 天梁 / 七杀 / 破军）为骨架
- 论断体系：宫职（十二宫含义）× 星性（庙旺利陷）× 四化（禄权科忌飞化与落宫）× 自化 × 三方四正联动
- AI 解读的 system prompt 固定声明三合派口径，禁止跨流派混用（不掺飞星派宫位互飞、不掺四化派自化体系之外的自创规则）

## 二、历法与时间口径

### 农历换算

- 基于 lunar-javascript 农历算法库（公版历法数据）

### 真太阳时

- 按出生城市经度做真太阳时校正（内置中国主要城市经度表，校正精确到分钟级）
- 同一城市的区县经度差按全市跨度折算，误差控制在约 5 分钟内

### 夏令时与时区平移

- 中国大陆 1986–1991 年夏令时段自动校正（+1 小时回拨）
- 当年时区与现行时区不同的情况按差值平移
- **跨日规则**：平移结果跨日（不在 0:00–23:59 内）时一律返回空、不替用户改日期——因农历月大小、闰月、晚子时换日三者交织，擅自改日会引入不可审计的错误

### 闰月归属（流派分歧项，用户可选）

闰月生人的月柱归属存在流派分歧， fatepan 提供三种策略由用户自选：

1. **归本月**（上半月按本月、下半月按下月之外的口径以站内选项为准）
2. **归下月**
3. **前后半分**（闰月前半按本月、后半按下月）

选择结果随命盘持久化，保证同一命盘重复排盘结果一致。

### 时辰

- 23:00–01:00 为子时（按传统十二时辰制）
- 子时换日的流派分歧（晚子时是否换日柱）在八字相关功能中按保守口径处理，紫微排盘以农历日直接起盘

## 三、海外用户口径

- 排盘历法基准为中国时区（北京时间 UTC+8）
- 海外出生用户需将出生当地时间换算为出生地对应的中国时区时间填写（站内提供换算说明）
- 出生地不在内置城市表时，真太阳时校正按最近城市近似

## 四、解读层口径

- 70 段主星论断的完整口径见 [14-stars/](14-stars/) 与 [classics.md](classics.md)
- AI 解读优先引用知识库原文，知识库未覆盖的组合给框架性提示而非硬结论
- 高风险场景（健康 / 法律 / 财务）一律不替代专业建议
